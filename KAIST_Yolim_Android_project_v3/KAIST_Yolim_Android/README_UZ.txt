KAIST yo‘lim — Android ilova loyihasi

Ilova siz yuborgan HTML saytdan tayyorlandi. Darslar, testlar, tez hisob o‘yini,
XP va profil ma’lumotlari telefon ichida ishlaydi. Internet talab qilmaydi
(YouTube video havolalari internet bilan ochiladi).

APK yaratish:
1. Kompyuterga Android Studio va Android SDK o‘rnating.
2. Android Studio -> Open orqali ushbu papkani oching.
3. Gradle Sync tugashini kuting.
4. Build -> Build Bundle(s) / APK(s) -> Build APK(s) ni tanlang.
5. APK: app/build/outputs/apk/debug/app-debug.apk

Telefoningizga o‘rnatish uchun APK faylini yuboring va Android sozlamalarida
ushbu manbadan o‘rnatishga ruxsat bering.

Paket nomi: com.kaist.yolim
Ilova nomi: KAIST yo‘lim
Minimal Android: 6.0 (API 23)


YANGI FUNKSIYALAR (2.0):
- Video darslarni YouTube havolasi orqali ilova ichidagi playerda ko‘rish.
- O‘yinlar: tez hisob, xotira juftliklari, rost/yolg‘on, tez yozish, reaksiya testi.
- Video ko‘rish uchun internet kerak.
